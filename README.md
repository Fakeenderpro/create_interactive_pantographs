Create Interactive Pantographs
A NeoForge 1.21.1 addon that makes the pantographs from Create: Electro Energetics interactive while they are assembled on Create trains.
Out of the box, a pantograph can only be toggled while it is a normal block in the world. Once it becomes part of a train contraption, it can no longer be clicked. This mod fixes that, and adds modes that let a train decide for itself which pantographs to raise: by direction of travel, or from a Create schedule.
